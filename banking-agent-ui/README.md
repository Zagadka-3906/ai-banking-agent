# Android 静态设计参考

打开 `index.html` 可查看原有 54 张设计稿。它们是视觉与交互讨论材料，包含固定示例数据和未实现的概念，并非应用功能清单或真实办理回执。各设计稿原文保留，便于回溯。

Android 已采用紫藤、墨色、月白及对应状态色。页面行为、风险等级、资金状态和可执行操作以当前 Android 与服务端实现为准，不由静态稿决定。

逐组检查、采用范围和暂未落地内容见 [设计稿与图标落地记录](../docs/设计稿与图标落地-2026-10-15.md)。原始图标参考位于 [output/imagegen](../output/imagegen/anyan-icon-v1.md)，Android 使用独立矢量资源。
