# 品牌在软件中的接入

品牌资源统一来自[最终原稿](final/README.md)。平台转换只改变文件格式和必要的小尺寸处理，不另画一套相似标志。

## Android

桌面使用暖石墨底、浅金符号，保留自适应安全区及 Android 13+ 单色图层。登录和会话恢复使用横向组合；深色模式使用浅金符号与白字。聊天、抽屉、历史和处理中标识共用开口 A 矢量，卡片卡面也使用同一符号。

资源位于 `android/app/src/main/res/`，公共标识组件为 `BankBrandMark.kt`，主题位于 `ui/theme/`。字标由 SVG 路径转换，不依赖设备字体；风险、涨跌与错误仍使用业务语义色。

## 本地与服务器运维台

两者共用 `deploy/panel/`。页眉、登录页与浏览器图标使用定稿，明暗模式跟随系统。公共图标通过 `/brand/{name}` 白名单路由提供，不需要管理 Cookie；业务接口继续鉴权。

网页使用相对地址，兼容本机根路径和服务器 `/panel/` 前缀。修改图标后检查 HTTP 返回、实际加载尺寸与 favicon，不为图片放宽整个反代路由。

## 更新与验证

Android 修改后重建并安装 APK；本地后台重启拥有页面的进程；服务器按[部署流程](../../../deploy/README.md)更新。Git 提交和推送不会自动更新安装包或服务器。

检查浅色、深色、390 px 窄屏、大字体、自适应裁切、单色图标和公开资源路由。历史专项与本次实际执行的验证分开记录，见[验证记录](../../验证记录.md)，不把旧构建通过描述为当前已发布。
