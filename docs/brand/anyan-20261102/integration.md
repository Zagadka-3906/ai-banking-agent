# Logo 在软件中的接入

唯一品牌原稿为 [开口 A · 暖石墨＋浅金](final/README.md)。

## Android

- 桌面图标：暖石墨背景、浅金前景，保留自适应裁切安全区和 Android 13+ 单色图层。
- 登录与会话恢复：使用路径构成的 AnYan 横向组合；深色模式为浅金符号配白字。
- 聊天回复、抽屉、历史记录与处理中标识：共用开口 A 矢量资源，沿用原有动画。
- 银行卡卡面：增加开口 A，正常卡面使用暖石墨。
- 公共主题：浅色使用米白与暖石墨，深色使用暖石墨与浅金。风险等级、涨跌和错误提示沿用业务语义色。

资源位于 `android/app/src/main/res/`；颜色和公共标识组件位于 `ui/theme/`、`ui/components/BankBrandMark.kt`。横向组合由定稿 SVG 的路径与组变换转换，不依赖设备字体。

## 电脑与服务器后台

二者共用 `deploy/panel/` 页面。登录页、页眉使用最终图标，浏览器使用专用 favicon；主题跟随系统明暗模式。

公开图标通过白名单 `/brand/{name}` 路由提供，不依赖登录 Cookie；业务接口仍按原方式鉴权。网页使用相对路径，可同时用于本机根路径和服务器 `/panel/` 前缀，不需要放宽 Nginx 路由。

## 使用更新

源码修改需要重新构建、安装 APK；公网版本按 `deploy/README.md` 指定 HTTPS 地址与项目 CA 构建。本地启动器下次启动会读取新页面；已运行的旧后台进程需重启。服务器通过原部署流程更新后生效，源码提交和推送不会自动更新云服务器。

验证覆盖 Android 构建与单元测试、原生图标透明区域和裁切、明暗输入可读性，以及后台图片路由、登录鉴权和联系人回归。具体执行结果以本次任务报告为准。

品牌接入时的历史专项：135 项 Android 单元测试、8 项模拟器原生图标／界面测试、73 项后台与联系人测试通过；Debug 与 Release 构建通过。浏览器已检查明暗模式、390 px 窄屏、Logo 与 favicon 的实际加载。Release APK 已核对公网 Core／Gateway 地址和项目 CA，未进行真实手机安装或云服务器发布。

上述数字只属于品牌接入当时的验证，后续 JVM 数量、APK 和服务器部署见[验证记录](../../验证记录.md)，不以此段推断当前发布状态。
