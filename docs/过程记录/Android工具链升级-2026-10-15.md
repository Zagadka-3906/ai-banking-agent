## 升级范围

此前 lint 的 18 条依赖提示来自 6 个版本坐标在不同构建变体中的重复报告。本次同步升级它们及所需工具链；新版 lint 新增的第三方版本提示也一并核对和升级，不通过禁用检查或添加 baseline 隐藏提示。

最低运行版本保持 API 26，构建使用 JDK 17。移除独立 `kotlin-android` 插件和旧 `kotlinOptions`，由 AGP 内置 Kotlin 继承 Java 17 字节码目标。Gradle Wrapper 由 9.8.1 生成，发行 ZIP 和 Wrapper JAR 对照官方 SHA256 校验，ZIP 校验值也写入 Wrapper 配置。

`gradle --version` 显示的是 Gradle 自身 Kotlin DSL 的版本，与应用的 Kotlin 编译器版本分别管理。

安装脚本、README 和 CI 同步版本；CI 在 JVM 测试、Debug APK 和测试 APK 之外，新增 lint 与混淆、资源压缩后的 Release 构建。

## 配套兼容修复

- Android 17 对 target 37 应用实施局域网权限限制。访问显式内网端点时，应用先显示权限说明，获得授权后才创建聊天 ViewModel 并恢复会话；拒绝后可重试或进入系统设置，返回应用时重新检查权限。公网服务及回环端点无需此入口，API 26–36 保持原行为。内网 DNS 对应的 HTTPS 域名可通过显式构建参数声明需要局域网权限，避免依赖 DNS 探测。
- 卡片详情在进入后台或离开页面时取消揭示请求并废弃请求代次。旧成功、旧错误及旧请求的清理回调都不能重新显示卡号或覆盖新请求；同时迁移 `LocalLifecycleOwner` 导入。
- 保留文字布局测试的实际行、字符边界与省略号检查。核对 Compose 1.12.1 源码后确认其语义段落仍可能使用父级宽度重建，不能仅以该段落容器宽度判断文字溢出。
- 新增实际 ML Kit OCR 回归：绘制卡号图像，运行识别，再经生产卡号解析函数核对结果，以覆盖原生库加载和识别流程。
- Material 3 1.4 不再传递依赖 `material-icons-core`，因此显式声明现有界面使用的基础图标库，其版本继续由 Compose BOM 管理。
- 按新版 lint 调整骨架组件的 Modifier 参数位置，以及偏好设置的 KTX 写入方式；会话字段仍在一次异步写入中更新。
- 按 Coroutines 1.11 的迁移要求，在当前会话的子作用域内启动工作，不再给 `launch` 直接传入替代 Job。新增父作用域取消回归，确认请求及排队中的持久化都会停止；会话代次与旧回包检查继续保留。
- 适配 Android 17 的系统 PIN 界面：等待系统窗口稳定后注入真实按键，不依赖其是否暴露可编辑的密码节点。验证仍要求真实系统认证成功或取消，以及对应回调和后台审批结果。
- 60 项设备回归使用 `BankingRegression` 运行时标记筛选，并核对 XML 中的实际执行数量、失败和跳过数量，避免多类筛选只运行首类时误判覆盖完整。

## 验证结果

| 验证 | 结果 |
| --- | --- |
| Android JVM | 87 项通过，无失败、无跳过 |
| 标准 `lintDebug` | 0 错误、0 警告 |
| Debug / 测试 APK / Release | 全部构建通过，Release 含 R8 和资源压缩 |
| API 37，16 KB 页大小 | 60 项回归通过，无失败、无跳过 |
| API 35 | 同组 60 项回归通过，无失败、无跳过 |
| API 37，真实系统权限 | 1 项通过：拒绝、重试、授权、创建 ViewModel、通过 `10.0.2.2` 登录隔离服务 |
| 16 KB 原生兼容 | Release ZIP 对齐检查通过；4 个 64 位原生库的 ELF LOAD 段均至少对齐 16 KB；实际 OCR 识别通过 |
| Windows 安装脚本 | CLI 23 原生命令实际安装校验及幂等运行通过，保留旧工具目录 |

设备回归包含延迟 HTTP / SSE 回包、旧 401 / 500、同账号重新登录、旧生物验证回调、真实系统 PIN 成功与取消、旧设备密钥恢复、卡号后台隐藏、输入与结果页、主题与大字体、图标及备份策略。通过 `annotation=com.aibanking.agent.BankingRegression` 选择 14 个测试类；网络场景运行于独立的 `scenario` 包、离线演示数据和 `18800 / 18810` 服务，系统权限用例另外验证开发默认的主机地址。

本机 Java 下载发生 TLS 故障，构建验证使用临时本机缓存逐字节转发官方 Maven，记录下载校验值；项目与 CI 仍使用官方仓库。旧 Compose 测试 Rule API 仍有编译弃用提示，本次保留其调度语义并完成实际设备验证；这与 lint 的依赖版本提示分别统计。
