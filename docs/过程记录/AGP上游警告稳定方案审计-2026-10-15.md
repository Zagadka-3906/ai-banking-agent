# AGP 上游警告稳定方案审计（2026-10-15）

## 结论

截至 2026-10-15 本轮查询，公开稳定渠道尚无能消除当前警告的已验证 AGP 升级方案。保留 AGP 9.4.1 / Gradle 9.8.1 / Kotlin 与 Compose compiler 2.4.21 / JDK 17 / SDK 37，以及前次完成的 Compose v2、登录同步和测试引擎 1.0.8 修复。

本次只补充审计依据与回归记录，不调整版本、修改插件二进制或隐藏警告。

## 官方渠道与源码证据

- 直接读取 Google Maven 的 AGP `maven-metadata.xml`，最新无预览后缀的版本仍为 **9.4.1**，最高预览版为 **9.5.0-alpha09**。元数据更新值为 `20261008162929`；发布说明页面标题“9.5.0”不能单独作为稳定版已发布的证据。
- 当前配置执行 `help --warning-mode=all -Dorg.gradle.deprecation.trace=true`，记录到同一种弃用项的 **51 次** `Configuration.setVisible(boolean)` 调用，均来自 AGP。`SourceSetManager.createConfiguration` 占 41 次，其余来自 `BasePlugin`、`TaskManager`、`VariantDependenciesBuilder` 和 `UtpTestUtils`，没有 Kotlin 插件或项目脚本直接调用。
- 对照实际 AGP 9.4.1 源码，调用发生在配置创建路径中，且直接、无条件执行 `isVisible = false` / `setVisible(false)`。这些类位于主插件 `com.android.tools.build:gradle:9.4.1` 中，不能通过单独升级辅助库或在项目里预设配置值来删除这些调用；修改本项目的 SourceSet / Variant DSL 也不能替代该插件实现。
- 下载并校验官方 sources JAR 后，**9.3.3 稳定版仍有同类 setter 调用**；**9.5.0-alpha09 源码已移除这些 setter 调用**。后者与发布说明中 issue 560282299 / 565740572 的修复记录一致。本轮没有采用或运行预览工具链，源码检查不等于完成其运行兼容验证。
- issue 560282299 的最新用户反馈仍报告 alpha09 有警告，但没有足够证据将该反馈归因于本项目已升级 Kotlin 后的同一调用路径。因此后续判断以具体版本、完整堆栈和实际任务结果为准，不只看 issue 状态或评论。

Gradle 官方说明：`Configuration.visible` 自 Gradle 9 起已无实际作用，计划在 **Gradle 11** 删除。该警告不表示当前构建失败，也不能把现有验证表述为“已经在 Gradle 10/11 上验证通过”。

## 稳定候选方案评估

| 方案 | 评估 |
| --- | --- |
| 保留 AGP 9.4.1 + Gradle 9.8.1 | 本轮采用；保留可见的已知上游警告，继续验证实际任务与设备行为。 |
| 升级更高稳定 AGP | 官方公开元数据中尚无 9.4.2 或稳定 9.5；暂时没有可采用的稳定升级目标。 |
| 改用 AGP 9.5.0-alpha09 | 源码中已有修复，但属于预览版，不满足本次稳定方案要求。 |
| 回退到 AGP 9.3.3 | 稳定源码仍有同类调用，不能解决根因。 |
| 回退到 Gradle 9.7.1 | 不能移除 AGP 调用，且仍在下列安全公告的受影响范围；本轮未执行回退验证。 |
| 使用 Gradle 8.14.6 | 虽有安全回补，但低于 AGP 9.4 所需的最低 Gradle 9.6.0，不兼容当前工具链。 |
| 使用 Gradle 9.7.2 安全回补 | 官方公告列为 Security Subscription 版本，非当前公开 OSS Wrapper 升级路径；本轮未下载、采用或验证。 |
| 反射、改写插件 JAR、关闭警告输出 | 不采用；无法作为稳定插件修复交付，且会失去原始诊断或官方字节一致性。 |

Gradle 9.8.1 官方发布说明列出三项高等级安全修复。公告明确受影响范围包含 9.0.0–9.8.0，公开修复版本为 9.8.1、8.14.6，因此没有为减少弃用提示回退到 9.7.1。

场景测试使用独立离线后端及专用模拟器，覆盖账号隔离、迟到回包/错误/设备验证回调、卡片敏感信息生命周期、结果页、待办/问卷、布局与真实 OCR。未访问正式银行、飞书或外部模型服务。

验证沿用本机临时 loopback 官方 Maven 缓存传输；候选源码 JAR 对照官方 Maven SHA1 校验。仓库与 CI 的官方依赖源保持不变。源文件下载、完整堆栈、令牌、日志和测试产物留在被忽略的 `build/agp-stable-audit-20261015` 等本机目录，不提交。

## 后续采用条件

公开稳定 AGP 发布后，先确认其 SDK 37 / JDK 17 / Gradle 要求及 Kotlin runtime dependency 兼容路径，再检查完整警告堆栈与实际依赖解析，运行 lint、Debug/Release 构建和两套模拟器矩阵。只有实际 XML、设备 protobuf、汇总 protobuf 的数量和状态一致，才判定设备回归完成。测试引擎覆盖仅在确认新 AGP 已自带修复组件后移除。
