# Android 账号切换端到端验证（2026-10-14）

## 环境与隔离

Windows、JDK 17、Android 35（Android 15）模拟器。使用新建的专用 AVD `bankagent-account-isolation-20261014`、`scenario` 应用包 `com.aibanking.agent.scenariotest` 和本机 18800／18810 端口。原有模拟器及普通应用包不变。

`scripts/scenario_backend.py` 使用独立状态目录、内存账本和每次运行生成的控制令牌；强制关闭飞书，`offline` 模式关闭在线模型。测试只操作虚构演示账户，日志、截图、控制令牌、APK 和模拟器数据均放在忽略目录，不提交仓库。

## 实测发现

首轮在张三退出并登录李四后，真实设备注册接口返回 `409 DEVICE_ALREADY_BOUND`。Android 原来为所有账户使用同一个 Keystore 签名密钥，而 Core 的设备 ID 由公钥生成，并且一个公钥只允许绑定一个账户。新会话可以登录，但无法注册本机，后续强验证不可用。

修复将新账户的签名密钥按主体隔离，保持同一账户重登时密钥稳定。恢复登录后重新核对设备注册，将设备 ID 与实际选用的 Keystore 密钥对应起来，私钥始终留在 Keystore；旧密钥仅在服务器确认属于当前账户时沿用。已撤销的旧密钥继续被拒绝，不能回退到新密钥绕过撤销；退出不删除其他账户的密钥。Keystore 的查找与生成串行执行，避免并发登录替换同一账户的密钥。

## 回归方法

- 延迟成功及旧 SSE 错误：A 的真实查询先完成，服务端发出首个真实阶段；设备确认已进入流式读取后，通过界面退出 A、登录 B 并查询 B 的余额，再显式释放 A 的旧进度、结果或 401／500 错误。
- 旧 HTTP 401：暂停 A 的任务面板响应，在 B 登录后释放；验证 B 不会被退出或显示 A 的错误。
- 同账号重新登录：即使主体仍为 A，也必须拒绝前一次登录的在途响应。
- 回调归属：在设备上捕获生产代码实际传给生物验证的闭包，分别验证跨账户和同次登录更换审批后的旧成功／失败回调。
- 系统验证：使用真实 Android 设备凭据弹窗和专用模拟器 PIN。弹窗占用触控期间，通过真实 ViewModel 与 HTTP 切换到 B；随后完成或取消旧弹窗，计数确认系统回调确实返回，再原样转交生产回调。另用实际审批按钮完成当前账户审批作为正控制。
- 存储恢复：检查 B 的真实余额、会话主体、加密聊天记录和短暂状态变化；清除 ViewModelStore 后重建 Activity，验证新 ViewModel 从存储恢复正确账户。仅做配置重建会保留 ViewModel，不能作为存储恢复证据。

服务端 `completed` 只表示 ASGI 发送完成，不能单独证明设备解码。设备侧 UI、状态和存储断言与真实系统回调计数才是判定依据。PIN 场景验证 Android 设备凭据路径，不代表物理指纹传感器测试。

## 复跑入口

先在两个终端以相同的临时 `BANK_SCENARIO_CONTROL_TOKEN` 启动隔离 Core／Gateway，运行目录必须位于独立测试目录：

```powershell
.\.venv\Scripts\python.exe scripts/scenario_backend.py core --run-dir build/account-isolation-e2e/backend --mode offline
.\.venv\Scripts\python.exe scripts/scenario_backend.py gateway --run-dir build/account-isolation-e2e/backend --mode offline
```

专用模拟器预设测试 PIN，并用 `adb -s <serial> reverse tcp:18800 tcp:18800` 和同样方式转发 18810。在 `android` 目录运行：

```powershell
$env:JAVA_HOME = 'D:\AndroidDev\jdk-17'
$env:ANDROID_SERIAL = 'emulator-5580'
.\gradlew.bat --no-daemon --offline --console=plain -PbankScenarioTests=true `
  '-Pandroid.testInstrumentationRunnerArguments.class=com.aibanking.agent.ScenarioAccountIsolationUiTest' `
  "-Pandroid.testInstrumentationRunnerArguments.controlToken=$env:BANK_SCENARIO_CONTROL_TOKEN" `
  "-Pandroid.testInstrumentationRunnerArguments.devicePin=$env:BANK_SCENARIO_DEVICE_PIN" `
  :app:connectedScenarioAndroidTest
```

控制令牌只用于测试服务。PIN 只用于专用模拟器，不应使用真实设备凭据；缺少 PIN 参数时系统弹窗用例会跳过，不能据此宣称全部通过。
