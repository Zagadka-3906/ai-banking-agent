# 真实模拟器演示视频

本轮已实现录制与字幕生成流程。交付文件为本机 `build/contest-upgrade/delivery/安言演示视频.mp4`，16:9 横屏、中文字幕、无音轨，时长少于 5 分钟。左侧为真实 Android 应用录屏，右侧字幕说明操作和边界，不使用合成交易 UI。

## 实际演示内容

1. 登录隔离虚构账户，绿色查询当前余额。
2. 按月份和类别分析账单。
3. 给李四转 300 元，展示黄区摘要、用户确认和 Core 回执。
4. 转 2000 元，展示红区审批、真实系统 PIN 认证、设备签名与 Core 回执。
5. 为生日锁定 1000 元，查看提醒和订单草稿任务。
6. 请求人工处理，展示原因与暂停说明，Core 核对锁资仍保留。

本片使用离线规则模式，不宣称模型参与全部对话。红区录制使用公开测试兼容码 `888888`，没有真实短信；绑定审批的一次性演示码另由设备回归验证。Android 系统认证窗口可能受防录屏保护呈黑屏，字幕如实说明；后续成功画面必须由实际 Core 回执支持。设备 PIN、会话令牌和签名材料不加入字幕或交付材料。

## 复现录制

仅在专用 API 35 AVD 上运行，先设置其设备 PIN。18800/18810 必须空闲，脚本创建并关闭自己的隔离服务，不操作普通 8000/8100 服务。

```powershell
$env:BANK_TEST_DEVICE_PIN = '专用模拟器的PIN'
.\.venv\Scripts\python.exe scripts/run_android_regression.py --serial emulator-5580 --output-dir build/contest-recording --test-class com.aibanking.agent.ContestDemoUiTest --minimum-tests 1 --record-demo
.\.venv\Scripts\python.exe scripts/make_demo_video.py --ffmpeg '本机ffmpeg.exe路径' --recording-dir build/contest-recording --output build/contest-delivery/安言演示视频.mp4
```

`ContestDemoUiTest` 通过实际输入框、审批按钮和任务面板操作，记录章节时间与真实截图；控制接口只重置隔离种子数据和读取 Core 状态。常规回归不运行录制类，只有显式录制参数才启用。

录制器保留原始 screenrecord，成片只裁掉测试启动前画面并添加字幕。`video-manifest.json` 记录来源、时长、章节数、规则模式与无音轨状态。原片、临时截图、日志和依赖二进制留在忽略的 `build/` 中，不提交到 Git。
