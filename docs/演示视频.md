# 演示视频脚本与分镜（目标 4 分 45 秒）

本文件只给出**镜头、内容、动效和转场设计**，不包含成片。最终视频须不超过 5 分钟。建议 16:9 横屏成片：左侧放 Android 模拟器竖屏录制，右侧放放大的操作提示和必要的 Core 结果；录制真实本机演示，不制作看似已成功的假交易画面。所有素材仅使用虚构账户，隐藏 `.env`、会话令牌与设备签名。

## 录制前准备

1. 按 [README](../README.md) 启动 Core/Gateway 和模拟器；确认两个 `/healthz` 均正常，应用登录 `user_zhang`。
2. 为红区片段准备模拟器屏幕锁/生物识别、已登记设备和演示 OTP。先在测试环境走通一次，正式录制前重置 Mock 状态或使用新的幂等消息。
3. 录屏只显示应用与必要的健康页。模型密钥可留空，避免网络波动；旁白明确“当前为规则回退”或“当前调用在线模型”，不要混淆。
4. 统一字幕：白字深蓝底，关键结果用绿色、阻断用橙红；画面动效控制在 0.2–0.4 秒，不遮盖审批摘要、OTP 提示或 Core 追踪号。
