## 复现

使用专用 AVD，在本机私下设置测试设备 PIN，参照《测试用例.md》运行：

```powershell
.\.venv\Scripts\python.exe scripts/run_android_regression.py --serial emulator-5580 --output-dir build/contest-recording --test-class com.aibanking.agent.ContestDemoRecordingTest --minimum-tests 1
```

可在运行前用 `adb shell screenrecord` 开始录屏，结束后停止自己启动的录屏进程并拉取 MP4。用例在 `/data/local/tmp/anyan-contest-*` 导出章节 JSON 和真实截图，避免测试编排器清除应用数据后证据丢失；拉取后按章节时间剪辑。运行结束应清理专用设备上的导出，不在个人手机执行测试重置。

视频证明界面与核心规则链路，不证明联网大模型回答质量、真实短信、生物识别、商户履约或全部真机兼容。PPT 与视频分别满足各自时限，现场讲解可按答辩提纲调整。
