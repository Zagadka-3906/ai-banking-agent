# 演示视频（≤5 分钟）与录制脚本

> **成片**：[docs/演示视频.mp4](演示视频.mp4)（4 分 33 秒，1080×2400 竖屏录屏，无音轨、以字幕卡分段）。本文件同时是录制脚本与分镜表，便于复核每一段的演示内容与预期结果。

## 1. 录制环境

- AVD：`bankagent`（Android API 35，模拟时钟 2026-09-25），安装默认**独立 APK**（`STANDALONE_MODE=true`）。
- 录制：`adb shell screenrecord --time-limit N /sdcard/takeX.mp4`，三段长镜头 + ffmpeg 拼接片头/片尾字幕卡（`imageio-ffmpeg` 提供内置 ffmpeg）。
- 沙箱账户：`user_zhang / Bank@2026`，红区 OTP `888888`，生物识别用模拟器设备 PIN（`1234`）代替指纹。
- 红区确认时出现的黑屏段是系统 BiometricPrompt 的 FLAG_SECURE 防录屏保护（正常安全行为）。

## 2. 成片结构与对应分镜

| 成片时间 | 内容 | 对应分镜 |
| --- | --- | --- |
| 00:00–00:02 | 片头字幕卡 | #0 |
| 00:02–01:37 | Take A：通知授权 → 张三快捷登录 → 「帮我查一下账户余额」→ 「这个月钱都花哪儿了」（模糊表达进账单分析） | #1、#2 |
| 01:37–03:15 | Take B：「给老婆转300买菜」先取消、再重发确认 → 「给李四转2000元」红区 OTP(888888) + 设备 PIN 后执行 | #3、#4 |
| 03:15–04:30 | Take C：「我有哪些自动扣费」→ 「把视频会员那个取消掉」（回指+确认）→ 卡包页 → 理财页 | #5、#7、#6 |
| 04:30–04:33 | 片尾字幕卡（仓库地址） | #9 |

> 演示未包含分镜 #5（账单异常专项）与 #8（跨场景生日联动）的独立段落：异常识别已在"钱都花哪儿了"的账单卡中展示；生日联动因实测发现复合长句解析缺陷（见[测试问题清单](模拟用户测试问题清单.md) #2/#18），为不影响演示完整性改以短句形态在答辩环节现场展示。

## 3. 录制与后期命令

```bash
# 录制（每段一段长镜头，结束后 time-limit 自动收尾）
adb shell screenrecord --time-limit 100 /sdcard/takeA.mp4
# 拉取与拼接
adb exec-out "cat /sdcard/takeA.mp4" > test-shots/takeA.mp4
# 字幕卡与拼接由 build_video.py 完成（imageio-ffmpeg 提供内置 ffmpeg）
```
