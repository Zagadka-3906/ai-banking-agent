## 重新录制

1. 按[本地开发](本地开发.md)启动独立实例，确认账户、后端地址和模型状态。
2. 记录源码提交、APK、设备与虚构场景。不要对共享云账本执行清理或故障注入。
3. 按[演示讲解](答辩提纲.md)录制查询、取消、确认、回执和语音草稿，保留足够上下文。
4. 检查系统通知、姓名、密钥、令牌、OTP、完整卡号和管理入口，移除不适合公开的内容。
5. 如剪辑或加速，明确说明；需要证明时序或响应时间时，另保留原始完整录制。

录制工具 `scripts/serve_contest_demo.py` 保留早期命名，属于隔离演示服务，不应替换日常后端或直接重置共享数据。新增截图只提交公开所需的小尺寸版本，原始视频、日志与临时工程留在本机。
