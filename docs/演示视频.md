- AVD：`bankagent`（Android API 35），安装默认**独立 APK**（`android/app/build/outputs/apk/debug/app-debug.apk`，`STANDALONE_MODE=true`）。

- 沙箱账户：`user_zhang / Bank@2026`，红区 OTP `888888`，生物识别用模拟器 PIN 解锁代替指纹。

## 3. 录制与后期命令

```bash

# 拼接与字幕卡由 scripts/build_demo_video.py 完成（imageio-ffmpeg 提供内置 ffmpeg）
```
