# 本地开发

本文从 GitHub 源码启动后端和 Android App。命令默认在仓库根目录执行，示例使用 Windows PowerShell；云端安装另见[服务器部署](../deploy/README.md)。

## 使用已构建的本地 APK

[v2.0.0-beta.1 Release](https://github.com/Zagadka-3906/ai-banking-agent/releases/tag/v2.0.0-beta.1) 提供模拟器版和 USB 手机版 APK，以及 `LOCAL-SETUP.md` 中文指南。安装预构建 APK 无需 Gradle 或应用编译工具链，仍需在电脑运行 Python 后端、配置自己的模型 Key；模拟器或 USB 连接需要 adb。

模拟器版固定连接 `10.0.2.2:8000/8100`，USB 版固定连接 `127.0.0.1:8000/8100`，后者需建立两条 `adb reverse`。两个 APK 使用相同应用 ID，按环境二选一安装，切换后重新登录。此 Release 不包含作者云端安装包或私有模型凭据；也可继续按下文从源码构建。

## 环境与克隆

| 组件 | 要求 |
| --- | --- |
| 后端 | Python 3.10–3.12，推荐 3.12 |
| Android 构建 | JDK 17 或 21；SDK API 37；Build Tools 36.0.0；platform-tools |
| 设备 | Android 8.0 / API 26 及以上；模拟器或开启 USB 调试的手机 |
| 完整模型体验 | 自有 DeepSeek API Key；云端语音另需可选 DashScope Key |

```powershell
git clone https://github.com/Zagadka-3906/ai-banking-agent.git C:\AnYan\ai-banking-agent
Set-Location C:\AnYan\ai-banking-agent
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
```

Android 项目须放在 ASCII 路径，包含中文的父目录也会导致 Gradle 检查失败。依赖安装需要网络；本机后端不等于离线模型。

## 首次配置

编辑 `.env`，填写自己的 `DEEPSEEK_API_KEY`，将 `BANK_AUTH_SECRET` 的占位符换为随机长密钥，保留 `BANK_REQUIRE_SESSION=1`。可用下面命令生成一个随机值，再填入文件；不要提交该值：

```powershell
.\.venv\Scripts\python.exe -c "import secrets; print(secrets.token_hex(32))"
```

已有账本、签名和会话依赖稳定的密钥，不要把这一步当作每次启动都要做的操作。可选 `DASHSCOPE_API_KEY` 用于取得用户同意后的云端转写。完整变量及默认值以[样例配置](../.env.example)为准。

## 启动、观察与停止

```powershell
.\.venv\Scripts\python.exe scripts/serve_local_panel.py start
Invoke-RestMethod http://127.0.0.1:8000/healthz
Invoke-RestMethod http://127.0.0.1:8100/healthz
.\.venv\Scripts\python.exe scripts/serve_local_panel.py status
```

浏览器打开 `http://127.0.0.1:9100`，可查看服务和虚构账户。启动器占用 Core 8000、Gateway 8100、面板 9100 与控制端口 19111；端口冲突时不会接管其他进程。

首次启动把仓库 `.env` 复制到 `%LOCALAPPDATA%\bank-agent\local-panel\<源码目录标识>\local.env`。实际数据目录会打印在启动输出中，账本、设备、会话与日志与源码分离。之后应编辑该 `local.env` 并重启相应服务，仓库 `.env` 不会自动覆盖它。本机面板不影响服务器账本，启动器也会关闭本地飞书监听。

```powershell
.\.venv\Scripts\python.exe scripts/serve_local_panel.py stop
```

停止保留数据。需要新场景时通过面板备份和恢复，不直接删除账本文件。

## 模拟器

通过 Android Studio 安装模拟器和系统镜像，创建名为 `bankagent` 的 AVD。已有工具链可直接运行：

```powershell
.\start-emulator.bat
```

它构建 Debug APK，启动或复用本机服务，安装并打开 App。模拟器通过 `http://10.0.2.2:8000/` 与 `http://10.0.2.2:8100/` 访问电脑。

如缺构建工具，可按需使用安装脚本，完成后重新打开终端：

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\android\tools\install-android-toolchain.ps1 -Base "$env:LOCALAPPDATA\AnYanToolchain"
```

该脚本不创建 AVD，也不代装全部系统镜像。红区演示前为专用模拟器设置屏幕锁并完成设备登记。

## USB 手机

手机开启 USB 调试并接受电脑授权。以下命令为单设备示例，多设备时使用 `adb -s <序列号>`：

```powershell
adb devices
Set-Location android
.\gradlew.bat :app:assembleDebug -PbankCoreUrl=http://127.0.0.1:8000/ -PbankGatewayUrl=http://127.0.0.1:8100/
Set-Location ..
adb reverse tcp:8000 tcp:8000
adb reverse tcp:8100 tcp:8100
adb install -r .\android\app\build\outputs\apk\debug\app-debug.apk
```

手动打开 App。USB 转发把手机回环地址连到电脑；断线或重启后按需重新建立。普通局域网 HTTP 不属于这条受支持路径，不能只改 IP 就假定客户端允许明文访问。

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ruff check . --ignore E402

```
