# 交互细节与来源

本文记录容易在界面改动中丢失的行为约定，以及第三方动效的来源。产品总体原则见[界面设计约定](UI建议.md)。

## 办理历史

日期和业务类型使用两栏独立的分段选择，不能让一栏切换重置另一栏。选中背景在约 320 ms 内移动，中途约 160 ms 时拉长至起止标准宽度较大值的 110%，落位后恢复；连续点击从当前位置承接，不累计放大。

长分类栏可横向滚动，大字体保留文字和点击区域。各项具有选中状态和 Tab 语义；减少动态效果时直接切换。删除历史记录需要确认，删除会话不撤销已完成的业务或审计。

## 处理中动画与许可

安言头像保持静止，旁边显示圆形、三角形与方形间变化的点阵。几何算法来自 [Jakubantalik/thinking-orbs](https://github.com/Jakubantalik/thinking-orbs)，移植为 Kotlin / Compose Canvas，不加载 WebView 或远程脚本。

来源提交为 `de85557ca220332586d070d8788c0e1d6e877a0d`，采用 `shaping/20` 参数，参考 `src/engine/morph.ts`、`src/engine/core.ts`、`src/engine/profiles.ts` 与 `src/presets.ts`。Copyright (c) 2026 Jakub Antalik，MIT 授权；[完整许可证](../android/app/src/main/assets/licenses/thinking-orbs-MIT.txt)随 APK 打包。

JVM 基准核对四个时间点的坐标、深度、半径和透明度，容差 0.0001。减少动态效果时使用代表帧，页面离开前台时停止刷新。动画只表示处理中，不表示模型推理可信或业务成功；历史设备专项和当前测试范围分别见[验证记录](验证记录.md)。

## 草稿与确认

新推荐按钮不覆盖用户已有草稿，过期推荐应清除。语音识别不自动发送。待确认卡绑定原业务，修改对象或金额应生成新提案；旧卡过期、取消或会话失效后不能继续付款。异常返回区分明确失败与未知结果，未知时查询原回执。

## 演示联系人

默认姓名“王美”与关系字段分开。张三联系人簿中 `SPOUSE` 显示“爱人”，李四联系人簿不会据此建立相同关系。旧称“王美（爱人）”仅作为兼容称呼，不作为新姓名展示。

加载旧签名账本时，仅修正原演示身份和自动生成联系人中的对应字段；保留用户自定义姓名、关系、删除状态、金额和历史记录。初始快照同步修正同类字段，迁移保持幂等，不借迁移重置用户业务数据。
