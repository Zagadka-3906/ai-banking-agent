# 交互细节与来源

## 办理历史

日期和业务类型分别使用一个分段控制器，两栏状态相互独立。选中项共享一个背景块；滑动时用 320ms 完成移动，中途 160ms 时宽度拉长至起始与目标标准宽度较大值的 110%，落位恢复目标宽度。连续点击从当前位置承接，不累计放大。长分类栏可横向滚动，大字体保留文字与点击区域，减少动态效果时直接切换。每项提供选中状态和 Tab 角色。

## 思考状态

安言头像保持静止，旁边展示 [Jakubantalik/thinking-orbs](https://github.com/Jakubantalik/thinking-orbs) 的 `working` 粒子轨道动画。原项目基于 Canvas 的计算移植为 Kotlin／Compose Canvas，采用 `working/20` 参数并适配主题前景色。应用无须加载网页、WebView 或网络脚本。

来源版本：`de85557ca220332586d070d8788c0e1d6e877a0d`。移植涉及 `src/engine/orbits.ts`、`src/engine/core.ts`、`src/engine/profiles.ts` 和 `src/presets.ts` 的几何与参数。Copyright (c) 2026 Jakub Antalik，MIT 授权；完整许可证随 APK 打包在 `assets/licenses/thinking-orbs-MIT.txt`。

Kotlin 单元测试对照上游四个时间点的全部坐标、深度、点半径和透明度基准向量，容差 0.0001；减少动态效果时展示静态代表帧，页面离开前台时停止逐帧刷新。设备专项比较两帧头像完全相同、粒子画面不同。

## 演示联系人

默认账户姓名为“王美”。张三联系人簿中的王美使用独立关系字段 `SPOUSE`，标签为“爱人”；李四的联系人簿不据此建立爱人关系。旧称“王美（爱人）”保留为兼容转账称呼，但不作为新姓名展示。

对旧签名账本，加载后仅纠正原演示身份与原自动生成联系人记录；自定义姓名和关系、已删除联系人、余额、历史交易和其他业务字段不改写。对应初始快照中的原演示身份也作相同字段修正，避免重置后再次出现错误姓名；快照金额和保存时间保持原值。迁移是幂等的。
