# 项目演示讲解

这是一条面向首次接触安言的观众的讲解路线，可按受众缩短或展开，适合现场体验、技术分享和项目介绍。

## 从用户目标开始

展示首页并提出一个完整问题，例如“这个月主要花在哪了”。说明安言试图减少入口查找，让用户先说目标，再由系统读取数据和解释。指出当前账单是虚构演示数据。

## 展示一次完整办理

提出给已有联系人小额转账，核对对象、金额与风险，先取消一次，证明确认前不扣款。重新发起并确认后，展示账本和回执。聊天文字、动画和预检不能代替成功结果。

## 展示语音与专门界面

打开语音面板，长按说话，上滑取消一段，再录一段松开转写。文字只进入草稿。打开理财频道，筛选风险与期限，说明公开产品和本人持仓分别读取；申购仍返回受控办理流程。

## 解释系统结构

用[系统架构图](assets/系统架构图.svg)说明 Android、Gateway 与 Core。模型负责理解、取证和规划，Core 独立决定权限与持久提交；运维台是单独的管理通道。复杂任务可以有先后依赖，中断不代表撤销已完成资金。

## 展示安全边界

在隔离测试账本中展示参数变更或重复执行被拒绝。讲清绿色自动、黄色确认和红色强验证，以及演示 OTP、设备签名、幂等和回执各自的作用。不要把演示验证称作真实银行认证，也不应在公开录屏中展示令牌或密钥。

## 让观众能够复现

给出[本地开发](本地开发.md)、[测试用例](测试用例.md)和[验证记录](验证记录.md)。区分本次现场演示、历史自动测试、真实模型任务和仍待验证的环境。最后说明 Mock 数据、外部模型依赖、单机持久化和真实商户未接入等限制。
