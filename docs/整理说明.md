## 交付目录生成

先完成相关验证并提交源码，再从仓库根目录执行：

```powershell
.\.venv\Scripts\python.exe scripts/package_contest_submission.py
# 保留已有 APK 且需要登记其构建来源时，可附加 --apk-source-commit 3a1bfd6
```

命令默认整理 `submission/`，从已提交 HEAD 导出完整源码目录，把[评审指南](评审指南.md)生成到 `03-源代码与部署材料/README.md`，文档副本链接指向展开源码。本次不转换格式，不处理或校验 PPT 与视频；二者按提交栏目分别保留，缺失也不阻止技术文档、源码和安全报告整理。原有作品简介收进第三栏补充材料，安装包在第三栏保留；APK 来源可选登记，未提供时不推断为当前源码。

如果发现旧目录结构、旧 ZIP 或展开源码中有额外文件，脚本拒绝继续，避免把旧包误作新交付或静默删掉用户文件；先核对具体文件再处理。目录生成不发布服务器，也不替代稳定候选门槛。
