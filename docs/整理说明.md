# 仓库结构与清理原则

公开仓库保留运行、开发、测试、运维和解释实现所需的文件。历史探索可从 Git 追溯，运行状态和私人材料不属于源码。首页提供[目录导航](../README.md#仓库导航)。

## 主要目录

| 位置 | 职责与保留依据 |
| --- | --- |
| `bank_agent/`、`agent.py`、`agent_api.py` | Agent 实现、兼容入口与网关服务 |
| `bank_core/`、`main.py` | 模拟银行业务与 HTTP 服务 |
| `bank_planning/`、`bank_security/` | 规划、协议、授权与安全支持 |
| `android/` | 客户端、资源、构建入口和测试 |
| `deploy/` | 服务器脚本、反代配置与共享运维台 |
| `scripts/` | 启动、评测、诊断、场景与维护工具 |
| `tests/` | 回归、契约与版本化任务数据 |
| `docs/` | 公共说明、同源规则、必要品牌原稿与轻量界面素材 |
| `tools/` | 保留有实际用途的辅助工具 |

根目录部分 Python 文件为既有导入、测试与 CLI 的稳定入口。迁移它们前须核对所有调用，不能仅因目录已模块化就删除兼容文件。

## 什么不提交

`.env`、API Key、SSH 私钥、运行账本、设备库、会话、日志、构建 APK、临时报告、原始视频和私人测试数据留在本机。`build/`、`tmp/`、`film/`、`design-demos/` 与交付目录已按用途忽略，忽略不等于允许删除用户已有文件。

README 的 SVG 头图、五张实际界面图和截图 GIF 是公开阅读需要的素材，不重新加入历史设计工程或大批重复截图。品牌目录只保留定稿与平台变体，第三方许可证随实际使用资源保留。

## 已清理的类别

此前从当前树移除 46 个历史设计与演示文件，以及无生产调用的旧动画、数字状态和专用测试，记录见提交 `bb56757`。有效动效与现有界面逻辑继续保留；移除闲置组件导致 JVM 测试由 140 变为 139，不代表隐藏失败。

本轮公开文档重写统一读者、部署路径、交互与安全边界，保留原文件名兼容旧链接。历史验证过程从 Git 获取，不把交付文件、私有云配置或旧 APK 当作公开安装前提。

## 以后如何清理

先查静态引用、动态加载、脚本、测试、资源名和部署路径，再决定保留、移动或删除。旧任务与评分副本可能用于发布门槛，Java 核对器可能被设备脚本调用，不能按后缀或年代判断无用。

对删除运行相关文件执行对应回归；文档更新检查本地链接、图片、代码示例和规则导出。只提交本次相关文件，保留原有未跟踪笔记及其他工作。[贡献指南](../CONTRIBUTING.md)
