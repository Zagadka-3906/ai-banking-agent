合计清理约 25 GiB 生成文件。旧模拟器目录中的 5 个 SDK 目录联接整体移入私有备份，未删除联接指向的 SDK 内容。另停止了已无原父进程、占用旧测试日志的 38 个历史测试工作进程，保留当前本机服务。
