# 项目整理说明

公开仓库保留可运行源码、构建定义、测试、部署工具、技术说明及品牌原稿。本地设计稿、录制素材、交付材料与运行数据不进入当前版本。删除的历史文件可从 Git 历史追溯。

## 当前目录与保留依据

| 路径 | 内容与保留理由 |
| --- | --- |
| `bank_agent/`、`bank_planning/` | 对话理解、讨论状态、取证、计算、任务规划和回答核验，仍有生产调用与回归覆盖 |
| `bank_core/`、`bank_security/` | 模拟银行、账本、会话、授权、设备签名、审计与风控 |
| 根目录 Python 模块 | 服务入口、共享接口和兼容导出；Gateway、脚本与测试仍通过这些入口调用 |
| `android/` | 客户端、当前界面和动画、JVM／设备测试及构建工具；保留实际使用的第三方许可证 |
| `deploy/` | 本地与服务器面板、服务配置和云端部署工具 |
| `scripts/`、`tools/usability/` | 启动、评测、规则导出、设备回归和可用性观察；详见[脚本索引](../scripts/README.md) |
| `tests/` | 回归、共享契约及版本化数据；旧数据承担协议和差异核对，详见[测试索引](../tests/README.md) |
| `docs/`、`docs/brand/` | 技术、安全、运行与版本说明，以及品牌原稿和平台变体 |
| `.github/` | 后端质量检查、Android 构建与设备回归工作流 |

品牌原稿与 Android／面板资源存在相同字节的副本，分别用于导出和实际运行，不能按文件哈希重复就删除。命令行工具和手动传入的评测数据也不能只因没有直接 import 就认定无用。

## 本次清理

- 从当前版本移除 `design-demos/` 的 46 个旧设计页面、截图、答辩 PDF／PPTX 和生成脚本，合计约 5.84 MiB。这些文件没有参与应用构建、后端运行或持续集成。
- 删除没有调用的立方体兼容动画、空阴影扩展、缩放与呼吸装饰、旧语音脉冲和数字滚动组件。同步移除仅为旧数字组件服务的状态、提供器与专用测试。
- 保留实际使用的入场、问候、风险光效、思考、返回预览及其他界面行为；不改变交易、确认或安全策略。
- 将 `/design-demos/`、`/film/`、`/tmp/` 加入忽略规则，避免本机设计、录制和制版产物再次入库；本机已有文件保留。
- 修正文档中“design-demos 未被跟踪”的旧表述，并在协作约定中明确中文提交说明与交付目录隔离。

## 本机文件与交付目录

`.env`、虚拟环境、会话、设备登记、账本、构建产物、测试输出及私有备份继续保留在本机，并按忽略规则排除。未跟踪的个人笔记和探测脚本也保留原位，不混入本次提交。

`submission/` 及交付压缩包是独立的本地评审材料。后续 GitHub 源码与界面维护不修改、不同步、不重新生成这些材料；只有用户重新明确要求时才处理。源码中的历史参赛整理工具及其回归仍保留，本次没有运行它们来更新实际交付目录。

## 验证与后续维护

清理后检查剩余引用、Android 单元测试、界面测试编译、应用构建、Lint、文档路径和相关工具回归。具体执行结果见[验证记录](验证记录.md)。
