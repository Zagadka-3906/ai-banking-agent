## 安卓复现

设置 `JAVA_HOME`、`ANDROID_HOME`，按仓库配置安装工具链。在 `android/` 运行：

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug assembleRelease assembleDebugAndroidTest
```

隔离 variant 使用 `-PbankScenarioTests=true`，JVM 任务名为 `testScenarioUnitTest`。设备测试使用专用 AVD，勿使用个人手机。需要系统凭据的用例必须在本机私下设置专用模拟器 PIN。

```powershell
.\.venv\Scripts\python.exe scripts/run_android_regression.py --serial emulator-5580 --output-dir build/contact-regression --test-class com.aibanking.agent.ScenarioContactDeleteUiTest,com.aibanking.agent.UiClosureComponentsTest --minimum-tests 19
```

设备检查包括：取消删除不发请求、确认提交一次、返回关闭弹窗、重新登录后不恢复、页面重建保留确认对象、重复确认只提交一次、丢失回执后只读核对。主题专项 `DesignInputsUiTest` 检查明暗聚焦对比度、文本选择和大字体入口。
