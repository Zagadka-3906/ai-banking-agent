```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ruff check . --ignore E402
```

普通 pytest 使用隔离状态和受控模型替身，不连接共享银行账本，也不代表已经运行付费模型评测。CI 另生成后端分支覆盖率并进行可联网条件下的依赖审计；审计跳过必须与通过分开解读。

## 主要断言

| 领域 | 代表输入或故障 | 必须核对 |
| --- | --- | --- |
| 身份隔离 | 未登录、过期会话、改主体与对象 | 拒绝私有读取或写入，不返回他人数据 |
| 小额转账 | 明确对象和金额，先取消后重提 | 确认前不扣款，取消不执行，新确认得到回执 |
| 风险升级 | 当日先提 600 元再提 600 元 | 待执行授权参与累计，第二次按当前风险升级 |
| 参数绑定 | 修改金额、卡片、收款人、备注 | 旧授权不能用于新参数 |
| 重放与幂等 | 相同请求重复、同键改参数 | 不重复扣款，冲突请求拒绝 |
| 红区 | 缺失、过期或错绑定的 OTP / 设备证明 | 不执行；正确验证也仍检查实时业务条件 |
| 查询取证 | 空集合、失败、缺字段和旧证据 | 不把失败说成无记录，不用旧事实替代新读取 |
| 数值与回答 | 多目标、汇总、错误金额或成功声明 | 程序计算可追溯，缺证据保留逐项缺口 |
| 讨论与任务 | 暂停、恢复、改对象、取消规则咨询 | 只操作匹配任务，不恢复旧授权或撤销已完成资金 |
| 持久化 | 写盘失败、损坏签名快照 | 不报成功，回滚或冻结写入，保留原文件 |
| 通道边界 | 语音草稿、飞书写请求、订阅查询 | 语音不自动发送，飞书不办理，订阅仍需确认 |

任务数据与目录用途见[测试目录](../tests/README.md)。用例是已编码边界，不代表穷尽全部攻击或用户表达。

## Android

```powershell
Set-Location android
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug assembleRelease assembleDebugAndroidTest
```

JVM 测试核对状态、格式与规则，Lint 和构建核对静态质量与可编译性。`assembleDebugAndroidTest` 仅编译设备测试，不运行设备用例。真实设备或模拟器专项需隔离后端与明确目标设备，使用 `scripts/run_android_regression.py --help` 查看入口。

设备重点包括登录、SSE 对话、取消与确认、红区设备验证、回执、历史、大字体、明暗主题和理财筛选。语音核对长按松开、上滑取消、新一段、转写中离开与迟到结果，不能再按旧“点击完成”流程验收。

## 真实模型与发布门槛

先用 `scripts/evaluate_dialogue_tasks.py --dry-run` 检查计划，再在有预算时运行联网任务。保留模型、源码、数据和评分版本、每项失败、费用及未完成项。具体命令见[多轮任务评测](多轮任务评测.md)，发布条件见[稳定性门槛](稳定验收标准.md)。

接口健康、单轮演示、全量单元测试或一个总分均不能独立证明长期稳定。报告应注明使用模型替身还是实际服务、是否运行设备、是否包含生产网络和存储。
