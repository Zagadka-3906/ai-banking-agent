# 安全自评

本报告公开安言的已实现控制、验证依据和仍然存在的风险，供开发者判断是否适合自己的研究或演示环境。它是项目自评，不是第三方审计、银行认证或合规结论。

## 范围与结论

范围包括 Android、Agent Gateway、Mock Core、语音与飞书入口、持久化、审计和运维台。模型没有账本写工具，普通用户业务由 Core 独立校验。账户与资金均为虚构，系统适合受控演示，不宜直接处理真实金融资产或敏感客户数据。

## 权限实现

| 控制 | 实现方式 | 需要注意 |
| --- | --- | --- |
| 绿色自动 | 有效会话与本人资源校验后的普通查询 | 自动不表示匿名或跨主体读取 |
| 黄色确认 | 操作详情、主体绑定审批、Core 确认状态 | 小额累计计算含待执行授权；订阅查询也需确认 |
| 红色强验证 | 原审批、演示 OTP、登记设备挑战签名及实时条件复查 | 不是实际短信和真实银行身份核验 |
| 一次性授权 | HMAC 参数绑定、期限、唯一编号与消费记录 | 换金额、对象、业务或会话后重新预检 |
| 敏感卡号展示 | 会话加卡密码、限次和自动隐藏 | 单独信息展示路径，不宣称完整资金 MFA |

权限不由模型标签、客户端按钮或自然语言“我同意”单独决定。确认前不得扣款，已完成交易不能通过删除聊天或恢复讨论撤回。

## 其他防线

- 只读咨询采用固定资源、方法和主体，规则回源校验内容与实现版本。
- 回答使用当前证据与程序计算，生成后核验；成功必须有 Core 持久回执。
- 注入检测、协议白名单与核心授权共同防御越权，不能只依赖关键词过滤。
- 幂等、写盘失败回滚与加载失败冻结写入约束结果；超时后查回执而不自动再付款。
- 关键事件在 Core 与 Gateway 关联记录并脱敏，哈希链提供部分篡改检测。
- 表达式使用 AST 白名单、子进程和资源限制；模型请求采用有界并发和超时。
- 语音云端回退需同意，转写只入草稿；飞书依附有效 App 会话且只读。
- 运维台与普通用户权限分离，演示账户修改先备份，公网入口使用 HTTPS 与独立令牌。

## 验证如何解释

| 验证类型 | 能支持的结论 | 不能支持的结论 |
| --- | --- | --- |
| 后端回归 | 已编码的授权、隔离、幂等、计算和故障路径符合断言 | 所有真实输入、供应商和部署环境都安全 |
| Android JVM / 构建 | 状态与展示逻辑、代码编译及相应用例 | 已在真实设备验证全部流程 |
| 设备专项 | 指定构建、设备和场景下的实际界面或协议 | 完整机型兼容和长期稳定 |
| 联网模型任务 | 指定模型、任务和版本的实际表现 | 外部独立盲测或生产成功率 |

具体执行结果见[验证记录](验证记录.md)，复现命令见[测试用例](测试用例.md)。历史结果按原版本保留，不因重写报告而新增安全通过记录。

## 已知风险与应对

| 风险 | 当前限制 | 后续需要 |
| --- | --- | --- |
| 模型误判与核验相关错误 | 同模型独立调用仍可能一起漏判 | 新任务、人工复核、跨模型比较与失败分析 |
| 演示身份与共享账户 | 公开口令、演示 OTP，不是真实客户身份 | 独立身份、真实验证渠道、账户隔离与恢复流程 |
| 管理员与密钥权限 | 可修改程序、整段审计和签名数据 | 密钥托管、最小权限、异地审计与访问控制 |
| 单机持久化 | 无多实例事务、高可用和完整灾备保证 | 存储事务、恢复演练、故障注入与灾备方案 |
| 内存风控状态 | 部分失败窗口在进程重启后重建 | 持久计数、长期风险策略与监测 |
| 表达式隔离 | 不是 OS 级文件、网络和租户沙箱 | 容器或专用隔离服务及系统级限制 |
| 数据外发 | 对话与同意后的语音可发送模型服务 | 最小化字段、供应商策略、留存与删除机制 |
| 资源与费用 | 对冲、重试和外部调用可能额外收费 | 独立额度、供应商账单监测和容量测试 |
| 渠道和供应链 | 飞书策略、识别服务和依赖会变化 | 持续依赖审计、真实平台和设备复验 |
| 模拟商户 | 草稿和工单没有实际履约能力 | 如接真实系统，重新设计授权、回执与补偿 |

## 使用建议

使用专用虚构账户和测试设备，保持会话门禁，按需开放网络和模型能力。不要公开 `.env`、日志、账本、设备文件、完整卡号或管理令牌；演示密码不能复用到其他服务。真实金融用途需要重新开展业务、监管和安全设计，不能直接沿用本报告的结论。[安全设计细节](安全设计文档.md)
