# 项目介绍

## 项目简介

安言是一套银行 AI 智能体演示系统，让用户用自然语言查询账单、管理卡片、规划转账与理财任务。Android 客户端结合语音草稿和确认卡，LangGraph 组织理解、取证与执行流程，独立 Mock 核心校验身份、风险和授权。项目以可核对的回执与审计约束模型执行，提供源码、本地与服务器部署、运维台及自动化评测。全部金融数据和交易均为虚构。

## 为什么做安言

“安言”取安心表达之意。用户不必先找到每一个业务入口，可以先说出目标，再由系统澄清对象、检查条件和展示操作详情。自然语言降低入口成本，也带来歧义、错误推断和越权风险，因此理解能力与执行权限需要分别设计。

## 项目组成

Android App 承接文字、语音、产品浏览和用户确认；Gateway 用模型与 LangGraph 组织目标、任务状态、证据读取和回答核验；Core 独立维护账户、授权、模拟资金与回执。运维台用于观察服务和配置虚构账户，评测工具用于隔离复现对话与安全边界。

## 面向谁

- 想了解完整 Agent 工程的开发者：从会话、规划到确认、提交和异常处理都有源码入口。
- 研究受控业务执行的团队：可以比较规则、证据和模型核验各自承担的职责。
- 希望改造交互流程的产品与设计人员：可以运行真实客户端，观察确认卡、语音取消和多场景任务。
