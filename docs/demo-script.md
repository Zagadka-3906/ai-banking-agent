# 5 分钟演示脚本（答辩/录屏）

目标：在 5 分钟内展示“自然语言 → 意图解析 → 分级风控 → 人机确认/MFA → 核心记账 → 可核验结果”的闭环。所有账户和验证码均为沙箱数据。

## 0. 开场（0:00–0:25）

讲解词：

> 这是一个银行 AI 智能体沙箱。模型只做意图理解和任务编排，资金变更必须经过 Core Banking 的服务端策略。绿色查询自动执行，黄色操作需要明确确认，红色操作需要多因子验证；每一步都可以审计。

画面：展示 `docs/architecture.md` 的分层图或应用首页，不展示任何真实密钥。

## 1. 绿色：余额与账单事实查询（0:25–1:05）

输入：`帮我查一下现在账户里还有多少钱`。

预期：无需二次确认，返回总余额、锁定金额和可用余额；强调数值来自 `/accounts/user_zhang/balance`。

输入：`查看今日账单`。

预期：返回流水列表和支出合计。若展示图表，说明图表由已核实流水聚合而来，不由模型猜测。

## 2. 黄色：小额转账与取消（1:05–2:00）

输入：`给我老婆转账 300 块买菜`。

预期：解析联系人“老婆”、金额 300，风险卡显示收款人和金额，图暂停在 `human_review`。

点击“取消”：展示“核心银行未做资金扣减”，说明取消路径可回退。

再次输入同一指令并点击“确认执行”：展示流水号、收款人和转出后余额；可刷新侧边栏核对余额变化。

## 3. 红色：大额转账与强验证（2:00–3:05）

输入：`给李四转 2000 元`（若当日累计尚未超过阈值，可先演示一笔 1000 元黄色交易，或在沙箱重置计数）。

预期：风险卡标为 RED，先显示 MFA challenge。故意不完成验证并尝试继续，核心服务应拒绝且余额不变；随后完成短信验证码与设备人脸票据（勾选活体核验后由模拟设备 SDK 对服务端挑战签名），才允许记账。

讲解词：

> 红区安全边界在服务端，不在浏览器按钮。测试结束后可在审计记录中看到 challenge、审批和执行结果。

> 本地演示可使用 .env 中的测试码；验证码由 Core `/auth/mfa/verify` 服务端校验并换发一次性 proof，不能把固定码当作生产控制。

## 4. 账单异常分析（3:05–3:45）

输入：`为什么我上个月花销这么大，有异常交易吗？`。

预期：展示类目分布、深夜/境外可疑流水提示和明细表。指出分析结论应引用具体流水；如果模型服务不可用，系统应返回可解释的降级结果而非编造成功。

可选年度演示：`请生成今年年度账单报告`。系统使用 `YEAR` 半开区间过滤并返回可追溯的分类事实。

可选理财演示：`帮我做风险评估，我是新手，低风险`，随后输入 `比较 CJ01002 和 AY90204`；两者均为绿区事实查询，申购仍必须走红区 MFA。

## 5. 跨场景联动（3:45–4:35）

输入：`我爱人生日是下周，帮我锁定 1000 元活期，生日前 2 天提醒我订花和蛋糕`。

预期：Agent 拆出日期、预算、锁资、提醒和鲜花/蛋糕订单草稿，黄色确认后锁定资金；页面显示待办卡。展示余额中 `locked_amount` 增加、可用余额相应减少。到期运行任务中心后，订单草稿进入 `WAITING_USER`，不会静默下单。

讲解任务依赖：先锁资成功，再创建提醒；任一节点失败都应停在待人工处理状态，不得重复扣款。

可选红区演示：输入 `修改我的登录密码`，展示同一套 OTP+人脸挑战；Mock 只轮换凭证版本，不保存明文密码。

## 6. 收尾与安全承诺（4:35–5:00）

展示：`docs/security-self-assessment.md` 的权限矩阵和测试命令。

讲解词：

> 我们把模型当作不可信的建议者，把 Core API 当作唯一记账边界；采用白名单工具、分级权限、一次性凭证、MFA、审计和熔断。已有 argon2id 口令登录、登出吊销，账本/审批/设备库可 HMAC 校验落盘；生产化前仍需数据库事务、OIDC、真实 MFA、多实例一致性和合规评审。

## 录制前检查清单

- 启动 Core：`python -m uvicorn main:app --port 8000`。
- 启动前端：`python -m streamlit run web_app.py`。
- 确认 `DEEPSEEK_API_KEY` 通过安全环境变量注入；不要把 `.env` 或密钥录入视频。
- 清空/重置沙箱账户和每日累计，保证演示结果可重复。
- 预先运行 `pytest -q`（全量 7 个测试文件），记录版本和失败用例。
- 准备离线降级话术：LLM/API 不可用时只展示“无法完成，请稍后重试”，不声称交易成功。
