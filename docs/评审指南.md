# 项目导览

这份导览帮助第一次接触安言的人，从可见行为走到实现依据。无需预先了解模型或银行核心的内部结构。

## 先体验一条完整链路

按[本地开发](本地开发.md)启动服务与 App，登录虚构账户 `user_zhang`。先查询余额，再提出给已有联系人转一笔小额款项。核对待确认详情，取消一次，然后重新发起并确认，最后查看交易记录和回执。

观察四件事：缺信息是否补问；确认前账本是否不变；取消后是否没有执行；最终回复是否与账本和回执一致。不要仅凭聊天中的“已完成”判断资金状态。

## 认识三个容易混淆的状态

**理解了**表示模型形成候选目标；**待确认**表示服务端给出有期限的具体提案；**已完成**必须对应成功持久提交的业务回执。模型的计划和客户端动画均不能将前两个状态提升成第三个。

生日场景中的鲜花、蛋糕只形成模拟订单草稿。预约与 AA 不代表无条件后台扣款；已发生的转账也不能用回退任务图的方式撤销。
