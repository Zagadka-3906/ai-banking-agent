# 安言参赛评审指南

作品名称：安言：安全可控的银行 AI 智能体。本文供赛事评委核对作品、实现与证据；项目使用虚构账户、资金、产品和商户。

## 先运行作品

两种方式均可选择，完整步骤见[评审运行与部署说明](运行与部署.md)：

| 方式 | 入口 | 前提 |
| --- | --- | --- |
| 组委会本地部署 | 在第三栏 source/ 内配置 Python 和模型凭据，启动本机后端；构建本地 App，在模拟器或 USB 手机运行 | 构建环境与网络就绪，完整大模型能力需自行提供有效模型 Key |
| 使用作者云端 | 安装第三栏 `安装包/安言-公网演示.apk`，登录演示账户 | Android 设备可联网，作者云端及模型服务当时可用；无需本机后端或服务器管理权限 |

交付 APK 的后端地址在构建时固定为作者云端，不会自动发现本地服务。两条路径使用不同地址的 App 构建，数据、会话与设备状态相互独立。第三栏“部署说明.md”是本运行指南的副本，自行另建云服务器的高级维护步骤单独保留。

## 交付目录与运行

本地 `submission/` 与实际提交页面的五个栏目对应：

| 目录 | 要求与内容 |
| --- | --- |
| `01-技术文档/` | 必交；技术文档、核心算法说明、安全设计文档三份可分别提交的独立材料，架构图包含在正文 |
| `02-答辩材料/` | 必交；本次暂不处理 PPT 内容、格式和时长，已有文件原样保留 |
| `03-源代码与部署材料/` | 必交；评审版 README、部署说明、测试用例、验证记录、GitHub 仓库链接和展开的 source/ 源码 |
| `04-安全自评报告/` | 必交；权限分级实现说明与 R1–R22 已知风险 |
| `05-演示视频/` | 可选；本次暂不处理视频内容、格式和时长，已有文件原样保留 |

作品简介不是截图中的独立上传栏目，原有名称与报名简介放在第三栏的 `补充材料/作品简介/`；原有 APK 及公开 CA 保留在第三栏 `安装包/`。这些是补充资料，不替代四项必交材料。

进入 `03-源代码与部署材料/source/` 后，按[本地开发](本地开发.md)启动；云端安装见[部署说明](../deploy/README.md)。根目录 [README](../README.md)面向外部开发者，本页是评审版的维护源；整理脚本将本页生成到第三栏，第三栏运行材料的副本链接指向展开源码；第一栏三份技术材料不含此类阅读跳转，架构图和办理时序保留为图表；随文 assets/ 用于 PDF 制版，最终须嵌入各自 PDF，读者无需额外打开图片。

当前只整理目录，不转换文件格式，不压缩源码。`manifest.json` 记录已整理文件的源码版本与哈希，答辩和视频栏目标为暂不管理、未经本次验证；缺少 PPT、视频、媒体说明、FFmpeg 或 APK 均不妨碍整理技术文档、源码和安全报告。目录存在不代表答辩或视频已经完成。

配置、私钥、会话、设备登记、账本、运行日志和私有备份不随源码交付。APK 来源在提供构建提交时单独记录；未知来源不自动标成当前源码。整理不代表稳定发布认证。

## 演示与已知边界

现有视频为 47 秒真实 Android 录屏，使用隔离规则模式。10 元模拟转账实际完成，2000 元红区申请展示验证要求后取消。视频早于理财与语音的后续改版，不用于证明最终 APK 的全部界面；新版行为以源码和对应验证记录为准。现有 PPTX 也属于较早媒体快照，最新文字证据与媒体分别标注，详见[视频说明](演示视频.md)和[答辩提纲](答辩提纲.md)。

项目不接入真实资金、短信或商户履约。演示验证码可由 App 获取，设备登记也未达到真实银行认证强度；独立语义核验可能与生成模型发生相关错误。完整真机矩阵、真实 ASR 准确率、飞书平台撤权及稳定门槛要求的持续观察仍需补充，详见[安全自评](安全自评报告.md)。
