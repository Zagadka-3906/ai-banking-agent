# 安言文档中心

安言把自然语言交互、受控 Agent 与独立 Mock 银行核心组合成一套可运行的演示系统。这里按使用目的组织公开文档；第一次访问可先看[项目首页](../README.md)。

| 了解项目和能力边界 | [项目介绍](作品简介.md) → [项目导览](评审指南.md) |
| 在电脑和手机上运行 | [本地开发](本地开发.md) → [运行与部署](运行与部署.md) |
| 部署自己的服务器 | [服务器部署手册](../deploy/README.md) |

| 检查权限与已知风险 | [安全设计](安全设计文档.md) → [安全自评](安全自评报告.md) |
| 复现验证或比较模型 | [测试用例](测试用例.md) → [多轮任务评测](多轮任务评测.md) → [稳定验收标准](稳定验收标准.md) |
