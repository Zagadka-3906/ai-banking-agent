## 飞书新企业发布与真实验收（2026-10-15）

用户新建企业后，发布企业自建机器人「安言银行智能体（企业验收）」1.0.0。旧应用保留，没有重置或删除；新应用只开放本轮企业测试成员，未扩大外部共享。机器人仅申请私聊接收、以机器人发送两项应用权限，订阅应用身份 `im.message.receive_v1`，使用长连接。平台明确显示连接成功、已启用、已发布；新应用租户令牌探针 HTTP 200 / code 0。没有取得旧应用 21001 的具体命中策略，不能宣称旧应用的拒绝已解除。

真实操作环境：标准 Core / Gateway 监听本机 8000 / 8100；专用 API 37 模拟器安装普通 Debug 客户端 `com.aibanking.agent`，通过系统本地网络授权、实际登录虚构张三账户，从设备管理面板获取一次性绑定码。没有清空原有银行存储或应用数据。静态验收监听结束后才启动业务 Gateway，避免同一应用的多实例争抢事件。
