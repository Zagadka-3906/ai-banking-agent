曾以同一 Core 进程连续运行 24 项模拟器 UI 测试，20 项通过，4 项失败。失败项为黄区转账、红区转账、反诈红区以及误跑在普通构建中的场景矩阵。前三项受前序卡片测试造成的共享账本状态影响；分别在隔离状态下复测通过。场景矩阵现使用 JUnit assumption，仅在专用 `scenario` 构建运行。**完整 24 项共享进程复跑尚未完成**；该套件需要按用例隔离 Core 状态或使用专用场景服务。

冷启动时，预设 PIN 的模拟器可能停在 `RUNNING_LOCKED`，系统会把安装的 Activity 误报为不存在。先用设备 PIN 解锁并确认 `dumpsys user` 为 `RUNNING_UNLOCKED`，再运行插桩测试。红区弹窗可用 `android/tools/satisfy-biometric-prompt.ps1` 辅助输入本机演示 PIN。测试用 PIN 不属于银行凭据。
